# Интеллектуальная транспортная система управления средствами регулирования дорожного движения

Учебно-исследовательская браузерная имитационная модель регулируемого перекрёстка для демонстрации и сравнения режимов светофорного управления.

Проект разработан в рамках выпускной квалификационной работы бакалавра на тему «Интеллектуальная транспортная система управления средствами регулирования дорожного движения».

Демо: https://losslessmind.github.io/its-simulation/

## Назначение

Приложение моделирует работу одного регулируемого перекрёстка в браузере. Имитационная модель позволяет наблюдать формирование очередей, переключение светофорных фаз, движение автомобилей и пешеходов, а также сравнивать режимы управления по среднему ожиданию, пропускной способности и другим метрикам.

Проект не является промышленной интеллектуальной транспортной системой и не предназначен для управления реальными светофорными объектами. Результаты моделирования относятся только к условиям разработанной программной модели.

## Основные возможности

- визуализация регулируемого перекрёстка на Canvas;
- моделирование четырёх направлений движения и двух полос на каждом направлении;
- генерация транспортных потоков по сценариям нагрузки;
- учёт автомобилей, пешеходов, очередей и времени ожидания;
- режимы светофорного управления: адаптивный, фиксированный, Вебстер, ручной, ночной и пешеходный;
- фазовый цикл `ns_main → ns_left → ew_main → ew_left`;
- сбор статистики и отображение графиков;
- журнал событий с фильтрацией;
- экспорт журнала в TXT и истории фаз в CSV.

## Режимы управления

| Режим | Назначение |
|---|---|
| Адаптивный | Изменяет параметры фаз на основе состояния очередей и времени ожидания. |
| Фиксированный | Использует постоянные длительности фаз и служит базовым режимом сравнения. |
| Вебстер | Использует расчёт длительности фаз по формуле Вебстера. |
| Ручной | Позволяет пользователю вручную выбирать активную ось движения. |
| Ночной | Имитирует мигающий жёлтый сигнал. |
| Пешеходный | Предоставляет приоритет пешеходному переходу, автомобили стоят. |

## Сценарии нагрузки

В симуляции используются сценарии с разным характером транспортного потока:

- пустая дорога;
- утренняя нагрузка;
- вечерняя нагрузка;
- пробка;
- случайная нагрузка;
- час пик (`rushhour`);
- суточный сценарий.

## Структура проекта

```text

```

## Технологии

Проект реализован без серверной части и сторонних фреймворков:

- HTML5;
- CSS3;
- JavaScript ES6;
- Canvas API.

Приложение может запускаться локально в браузере и размещено на GitHub Pages.

## Запуск

Достаточно открыть файл `index.html` в современном браузере.

Для локального запуска через простой сервер можно использовать:

```bash
python -m http.server 8000
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:8000
```

## Тестирование

Статус: сравнительное тестирование выполнено, результаты используются в главе 3 ВКР.

Проведено сравнительное тестирование режимов управления: 15 прогонов, 3 режима × 5 сценариев. Каждый прогон длился 300 секунд симуляционного времени.

Средние результаты по пяти сценариям:

| Режим | Среднее ожидание, с | Среднее число обслуженных автомобилей | Средняя пропускная способность, авт/мин |
|---|---:|---:|---:|
| Адаптивный | 34,35 | 516,8 | 103,36 |
| Фиксированный | 37,45 | 467,8 | 93,56 |
| Вебстер | 47,29 | 346,6 | 69,32 |

По результатам тестирования адаптивный режим показал лучшие средние значения внутри разработанной модели. Режим Вебстера оказался лучшим в сценарии «Пустая дорога». В утреннем и вечернем сценариях фиксированный режим показал немного меньшее среднее ожидание, но адаптивный режим обслужил больше автомобилей.

Подробная методика и таблица результатов приведены в файле [`docs/testing-plan.md`](docs/testing-plan.md).

## Ограничения модели

- моделируется один регулируемый перекрёсток, а не городская дорожная сеть;
- не используются реальные данные дорожных датчиков;
- не учитываются погодные условия, аварии, общественный транспорт, спецтранспорт и поведение реальных водителей;
- результаты тестирования показывают поведение алгоритмов только в рамках разработанной имитационной модели.

## Статус

Проект используется как практическая часть ВКР и как демонстрационный инструмент для анализа режимов светофорного регулирования.
