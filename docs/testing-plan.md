# План и результаты тестирования веб-симуляции

Статус: тестирование выполнено, результаты используются в главе 3 ВКР.

Демо проекта: https://losslessmind.github.io/its-simulation/

## Назначение тестирования

Тестирование проводилось для проверки корректности работы реализованных режимов светофорного управления и сравнительной оценки их поведения в одинаковых сценариях транспортной нагрузки.

Тестирование относится только к разработанной веб-симуляции регулируемого перекрёстка. Полученные результаты не являются доказательством промышленной эффективности интеллектуальной транспортной системы и не распространяются на реальные городские условия без дополнительной проверки.

## Проверяемые режимы

| Режим | Описание |
|---|---|
| Адаптивный | Использует текущие показатели очередей и ожидания для выбора и настройки фаз. |
| Фиксированный | Работает по постоянным длительностям фаз без учёта текущей нагрузки. |
| Вебстер | Рассчитывает длительности фаз по формуле Вебстера на основе интенсивности потока. |

## Проверяемые сценарии

| Сценарий | Назначение |
|---|---|
| Пустая дорога | Проверка поведения при низкой транспортной нагрузке. |
| Утренняя нагрузка | Проверка направленного потока в утреннем сценарии. |
| Вечерняя нагрузка | Проверка обратного направленного потока. |
| Пробка | Проверка поведения при высокой нагрузке. |
| Случайная нагрузка | Проверка работы при изменяющейся интенсивности потока. |

## Методика

1. Выполнить сброс состояния симуляции.
2. Выбрать сценарий транспортной нагрузки.
3. Выбрать режим управления.
4. Запустить симуляцию.
5. Провести прогон длительностью 300 секунд симуляционного времени.
6. Зафиксировать показатели из вкладки статистики.
7. Повторить процедуру для всех комбинаций режимов и сценариев.

Всего выполнено 15 прогонов: 3 режима × 5 сценариев.

## Сравниваемые показатели

Основные показатели:

- среднее время ожидания, с;
- максимальное время ожидания, с;
- количество обслуженных автомобилей;
- итоговая очередь;
- пропускная способность, авт/мин;
- количество завершённых фаз;
- количество пропущенных левых фаз.

Дополнительные показатели, которые могут использоваться при анализе:

- распределение обслуженных автомобилей по направлениям;
- распределение автомобилей по манёврам;
- количество пешеходов;
- количество конфликтов;
- среднее ожидание по направлениям.

## Интерпретация результатов

По данным проведённых прогонов адаптивный режим показал лучшие средние значения по совокупности сценариев. Среднее время ожидания составило 34,35 с, а средняя пропускная способность — 103,36 авт/мин.

Фиксированный режим показал среднее ожидание 37,45 с и среднюю пропускную способность 93,56 авт/мин. В утреннем и вечернем сценариях фиксированный режим имел немного меньшее среднее ожидание, чем адаптивный, однако адаптивный режим обслужил больше автомобилей.

Режим Вебстера показал лучшие значения в сценарии «Пустая дорога»: среднее ожидание 14,93 с, 179 обслуженных автомобилей и пропускная способность 35,8 авт/мин. При более высокой или переменной нагрузке его показатели оказались ниже, чем у адаптивного и фиксированного режимов.

В сценариях «Пробка» и «Случайная нагрузка» адаптивный режим показал наиболее устойчивое преимущество по среднему ожиданию, числу обслуженных автомобилей и пропускной способности.

## Ограничения тестирования

- Каждый сценарий был проверен одним прогоном для каждого режима.
- Для повышения статистической надёжности желательно выполнять несколько повторных запусков и усреднять результаты.
- Модель описывает один регулируемый перекрёсток, а не сеть перекрёстков.
- В тестировании не используются реальные данные дорожных датчиков.
- Не учитываются погодные условия, аварии, общественный транспорт, спецтранспорт и индивидуальное поведение реальных водителей.
- Результаты характеризуют только работу реализованной веб-симуляции в заданных сценариях.

## Вывод для ВКР

Результаты тестирования подтверждают работоспособность разработанной веб-симуляции и возможность сравнительной оценки режимов светофорного управления. В рамках заданной модели адаптивный режим в среднем обеспечил меньшее ожидание и большую пропускную способность, чем фиксированный режим и режим Вебстера. При этом преимущество адаптивного режима проявилось не во всех сценариях: при пустой дороге лучшим оказался режим Вебстера, а в утреннем и вечернем сценариях фиксированный режим имел немного меньшее среднее ожидание.
